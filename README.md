# Mini Golf Web

## 🎯 À propos du projet

Ce projet est une adaptation web d'un jeu Mini Golf développé à l'origine en **C++ avec Qt** pour ma **Deuxième Session à l'université de Sherbrooke**.

## 🌐 Version Web

Le jeu a été porté en **HTML5/Canvas/JavaScript** pour pouvoir être joué directement dans un navigateur web, facilitant ainsi le partage et l'accès via **GitHub Pages**.

## 🎮 Comment jouer

1. **Visée** : Cliquez et déplacez la souris pour viser
2. **Puissance** : Plus vous écartez la souris de la balle, plus le tir est puissant
3. **Tir** : Relâchez le bouton de la souris pour frapper la balle (ou appuyez sur Espace pendant la visée)
4. **Pause** : Bouton pause disponible à tout moment (même pendant que la balle roule)

## 🎵 Fonctionnalités

- **8 niveaux** avec différents terrains (normal, sable, glace)
- **Système de score** sauvegardé automatiquement
- **Physique réaliste** avec collisions et rebonds
- **Musiques et sons** adaptés à chaque environnement
- **Interface moderne** avec animations et effets visuels

## 🚀 Déploiement

Le jeu peut être déployé gratuitement sur **GitHub Pages** pour un accès web immédiat.

## 📁 Structure originale

Le projet original en C++/Qt contient :
- `Mini-Golf.pro` - Fichier projet Qt
- `Mini-Golf/` - Code source C++
- `Terrain/` - Fichiers de niveaux (.txt) et images (.png)
- `Graphic/` et `Son/` - Assets graphiques et audio
